# Nintavur-Vta-Part-Time-Courses-Name-List
This project is an official student search and certificate inquiry portal developed for the VTA of Sri Lanka at the DVTC - Nintavur, Ampara branch. It serves as a central interface for verifying trainee records and certificate statuses for various part-time courses, such as "Quantity Surveying - of BOQ" and "Surveying and Levelling."
