# Nintavur-Vta-Part-Time-Courses-Name-List
This project is an official student search and certificate inquiry portal developed for the VTA of Sri Lanka at the DVTC - Nintavur, Ampara branch. It serves as a central interface for verifying trainee records and certificate statuses for various part-time courses, such as "Quantity Surveying - of BOQ" and "Surveying and Levelling."
Key Features
NIC-Based Search: Efficiently search student records using National Identity Card (NIC) numbers.

Dynamic Data Rendering: Displays comprehensive trainee information, including:

Full Name with Initials.

Course Name, Year, and Batch.

MIS Number and Fingerprint ID.

Certificate Status (Complete, Not Complete, Dropout, or Participation).

Certificate Number, Back Serial Number, and Effective Date.
